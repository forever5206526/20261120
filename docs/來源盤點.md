## 4. 已確認的功能入口
`Extensions.yml` 列出：
- GetPacketKeys：取得載入客戶端使用的封包金鑰。
- ExtractTxtNames：擷取客戶端內嵌 TXT 檔名。
- ExtractMsgStrings：擷取客戶端內嵌 msgstringtable。
- DumpImportTable：輸出匯入 DLL 與函式清單。
- GenMapEffectPlugin：產生 MapEffect 外掛（標示為實驗性）。

`Patches.yml` 以多個分類檔載入修補項目，包括 Character、Client、Data、Env、Misc、Network、Sound、Special、UI、Window、Premium。需逐檔分析實際補丁內容及適用版本後，才可決定使用哪些項目。

## 6. 來源完整性與限制
本文件依 WARP 公開 GitHub 主分支的 README、設定檔與目錄清單建立，尚未執行 WARP，也未對使用者的遊戲客戶端進行任何修改。WARP 專案提供的 Windows 執行檔與 DLL 不應在未確認來源、雜湊及相容性前直接混入正式客戶端。
