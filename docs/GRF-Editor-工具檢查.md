## 3. 已由內附說明確認的用途

`Readme.txt` 說明 GrfCL 是供 CMD 使用的 GRF 命令列程式，功能與 GRF Editor 相同，並可透過批次檔自動化。內附批次範例展示：

- 解包 GRF 至資料夾。
- 從資料夾建立 GRF。
- 將指定檔案加入 GRF。
- 合併兩個 GRF。
- 由兩份 GRF 建立差異補丁。
- 變更 GRF 格式版本（範例列出 0x102、0x103、0x200）。
- 重新命名 GRF 內的檔案。
- 顯示 GRF 與檔案資訊。
- 從 ACT／SPR 製作 GIF。

因此，這套工具可作為後續客戶端 GRF 資源盤點、抽取、比對與重新封裝的候選工具。

## 4. 繁體中文相容性限制

內附「Extract a GRF to the current folder.bat」範例明確指定：

```bat
set c=%c% -encoding 949
```

這只能證明範例批次檔使用 949 作為抽取編碼，不能證明 GrfCL 已正確支援 CP950、Big5 檔名或繁體中文資料夾路徑。其他範例也包含舊式 ANSI／韓文編碼內容，不能直接當作繁體中文設定使用。

在 Windows 實測前，不應：
1. 將 949 改成 950 後就宣稱相容。
2. 用此工具覆寫使用者原始 GRF。
3. 將批次範例中的路徑、語系或編碼直接套用至正式客戶端。
4. 假設工具能正確處理所有新式 GRF／加密格式。
