# 專案規劃與進度

## 1. 專案目標
以使用者提供的 Ragnarok Online 客戶端素材為基礎，製作繁體中文版客戶端；使用 WARP 作為候選分析／修補工具，待登入器到位後再評估整合。最終交付可追溯的修改檔案、操作說明、測試報告及版本紀錄。

## 2. 重要技術辨識
WARP2026-Project 的 README 將 WARP 定義為 Win App Revamp Package：以 JavaScript（ECMA-262）腳本查詢及修改 32 位元 Windows 應用程式的工具，核心使用 C++ 與 Qt。它不是 Ragnarok 遊戲客戶端本體，也不是登入器。因此本專案先將 WARP 視為候選分析／修補工具，不假定它能直接完成所有中文化工作。

本次收到的 EXE 為 PE32、Intel i386／32 位元，檔案大小 16,499,200 bytes。已記錄 SHA-256，並進行只讀的 WARP 補丁簽章掃描；沒有執行或修改 EXE。

## 3. 執行階段

### A：素材與版本盤點
- 取得完整客戶端資料夾、GRF、DLL、Lua／資料表，以及後續提供的登入器。
- 列出檔案、資料夾、大小、格式及 SHA-256。
- 確認客戶端 EXE 位元數、WARP 解析的 BuildDate、語系資源、字型、封包／協定設定及資料檔格式。
- 保留原始素材唯讀副本，建立可回復工作副本。
- 核對 Session 的 `from` 檔名與實際收到的 EXE；目前兩者名稱不完全相同，尚未證明為同一位元版本。

### B：中文化方案確認
- 盤點現有繁體／簡體／英文語系資源及字串表。
- 確認字元編碼（例如 UTF-8、UTF-16、CP950／Big5 或客戶端自訂編碼），不可未檢查就批次轉碼。
- 建立台灣繁體中文術語表、字串長度與 UI 版面檢查規則；目前已建立 8 項 CP950 候選映射，待畫面校對。
- 區分可翻譯文字、不可翻譯識別字及需維持原格式的資料。
- WARP 的 `TranslateClient` 僅替換部分硬編碼文字，不能代替 GRF／資料庫／Lua／訊息字串表的全面中文化。

### C：分模組製作
- 優先處理可逆且風險較低的語系文字與設定。
- 再處理字型、字元顯示、介面資源及圖片文字。
- EXE／DLL 等二進位檔僅在確認版本、格式及修補位置後處理；每次修改保留差異及回復方式。
- 不擅自修改伺服器位址、封包版本、加密／防護、登入驗證或其他未確認設定。
- WARP 補丁先進行相容性與相依性檢查，完成後才製作另存的候選 EXE。

### D：登入器整合
- 收到登入器後確認來源、版本、啟動參數、工作目錄、更新流程及客戶端檔名。
- 依登入器及伺服器實際協定，在 `UseOldLogin`／`UseSSOLogin` 中選擇一種，不同登入模式不可疊加。
- 驗證登入器啟動、參數傳遞、更新及錯誤提示。
- 不移除原有安全檢查，不植入未經授權的憑證或帳密。

### E：測試與交付
- 驗證檔案完整性、繁體字顯示、字型缺字、介面截字／溢位、啟動流程及登入器相容性。
- 建立可自動化檢查；需 Windows 圖形介面或遊戲伺服器的項目標記為待實機測試。
- 產出安裝／更新／還原說明、變更清單及測試報告。

## 5. 已發現的相容性風險
- Session 指向的來源檔名帶有 `VHL_v4`，本次收到的檔名沒有 `v4`；必須先對照原始檔雜湊。
- 兩種登入模式互斥；`NoLoginOTP` 會改寫登入封包參數，需依登入器與伺服器流程確認。
- `AlwaysAscii` 可能影響語系／字元處理，CP950 測試先不沿用。\n- `RestoreBattlegroundUI` 腳本存在，但目前 WARP 分類 YAML 及 `Tables/Patch.yml` 都沒有註冊項，需在 TestBench 確認 Session 是否識別。
- `ChangeGoldPCMaxPoints` 設為 900，必須和 rAthena 伺服器端 `battle.cpp` 同步。
- `CustomDLL`／`RestoreCpsDll` 涉及 `cps.dll`；尚未有完整 DLL 檔案以驗證版本及匯出函式。
- EXE 匯入表包含 `BaseSDK.dll`、`IAPSDK.dll` 及 Stove PC SDK 函式；需搭配實際登入器檢查。

## 6. 風險與控制
- **編碼錯誤：** 先辨識原始編碼並以副本測試，避免整包亂碼。
- **二進位損壞：** 每次修補前備份，修改後比對雜湊與檔案結構。
- **版本不相容：** 以客戶端與登入器實際版本為準，不套用其他版本補丁。
- **授權限制：** WARP 原始專案標示 GPL-3.0；分發其修改版或衍生作品前，須遵守授權條款並保留聲明。
- **測試環境不足：** 靜態分析不等於 WARP 補丁執行或 Windows 遊戲實機測試；未能執行的項目會明確標示。
